## Добавление профиля

Pull request может открыть кто угодно и на любой профиль — доказательство в любом случае
публичное, а ложную строку ловят проверки ниже, а не доверие к отправителю.

Прежде чем открывать PR:

1. **ID опубликован на собственном сайте организации.** Страница, которую человек может открыть и
   прочитать. Она и становится `evidenceUrl`.
2. **`https://<domain>/.well-known/odp.json` существует и перечисляет ID** — обязательно для `B`,
   `M` и `P`. Без него строку нельзя проверять машинно, и она будет `manual` / `unverifiable`.
3. **Одна строка на один pull request**, вставленная в порядке сортировки по `profileId`.
4. **Прогоните проверки локально:**

```bash
node tools/validate.mjs && node tools/build.mjs && node tools/recheck.mjs --only=<profileId> --dry-run
```

Коммитьте и `odp-directory-v0.6.csv`, и пересобранный `directory.json`.

### Как заполнить строку

- `checkMethod=auto` — только если точка отвечает. Иначе `manual`, и тогда обязательны
  `archiveUrl` (снимок страницы-доказательства в Wayback Machine) и `lastVerifiedAt`.
- `displayName` — ярлык для удобства. Пишите название организации так, как оно указано на её
  сайте, без рекламных добавок и никогда — название, которого сам сайт не использует.
- `evidenceHost` обязан в точности совпадать с хостом из `evidenceUrl`.

## Что мейнтейнер проверяет перед merge

- CI зелёный.
- Домен действительно принадлежит организации — не похожий, не фанатский, не реселлерский. Это
  человеческое суждение, и именно поэтому merge не автоматический.
- Страница-доказательство действительно показывает ID.

Попадание в список — кураторское решение, а не сертификация. Мейнтейнер может отклонить строку,
даже если отправитель не сделал ничего плохого.

## Удаление профиля

Откройте issue. Строка переводится в `withdrawn` и сохраняется, чтобы приложения, закэшировавшие
запись, могли объяснить, почему она изменилась, а не забыли о ней молча.

## Изменение формата

Изменения формата идут сначала наверх. Откройте обсуждение в
[`object-digital-passport/specifications`](https://github.com/object-digital-passport/specifications/discussions):
нормативный источник — `SPEC.md` §4, а этот репозиторий следует за ним.
